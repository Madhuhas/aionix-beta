# AIONIX (Beta)

AI-powered shell/OS prototype. Natural language to commands via local Ollama (qwen2.5:0.5b). Modular engines: voice, memory, file mgmt, system monitor, app/package launcher. Windows-first, Linux-compatible.

## Features
- Voice input/output
- Personas (friendly/playful/minimal/dev)
- Memory/shortcuts
- Winget packages, file ops, psutil monitoring
- Run: `python shell/main.py` (Ollama required)

## Linux Port Goal
Replicate on Linux, wrap as full OS overlay.
